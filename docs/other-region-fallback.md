# 缺美国占比时使用其他地区代算（历史方案）

已被用户后续指令替换：美国值缺失时直接使用全球总量，当前规则见 global-fallback.md。本文仅保留先前方案的核验记录。

用户于2026-10-15确认：没有美国占比时，用 AppMagic 同一指标的“其他地区”合计占比代算，并计入均值。

- 优先使用同一指标的美国占比；缺失时才使用其他地区占比。两者都没有则保留未知，不填零。
- 各来源原始总量或范围阈值乘以所选占比，再对可用来源的结果求算术均值。
- AppMagic 自身的阈值只缩放一次；保留近似和范围符号，不把阈值宣称为精确值。
- 下载和收入分别选择占比，禁止跨指标借用。
- `shareBasis=us` 表示美国推算；`shareBasis=other_regions` 表示其他地区代算。
  后者的 `usPercent` 保持 null，实际代算占比存储于 `sharePercent`。
- 其他地区不等于美国，也不保证包含美国；这是用户选择的替代模型，不能视为美国实测。

来源证据：`data/appmagic-other-share-public-raw.json`。
对30个已有全球阈值、但缺少美国下载占比的应用逐页读取公开 DOM，核实 App Store ID，
读取最近30天小部件的全球阈值与灰色“其他”分段。其中24个取得可用其他地区下载占比，
6个没有可用分段，继续保留未知。已有收入美国占比保持优先。
完整地区原始行位于 `data/appmagic-us-share-raw.json`，各行保留采集时间。
