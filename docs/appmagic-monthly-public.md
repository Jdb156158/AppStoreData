# AppMagic 公开月度范围

验证时间：2026-10-14。入口：[公开工具类排行榜](https://appmagic.rocks/top-charts/apps?date=2026-09-01&tag=115)。

通过公开界面选择「月 / 2026年09月 / 全球 / 所有商店」，免费榜显示月下载范围，畅销榜显示月收入范围。细分清理、VPN、遥控、二维码和其他工具，分别读取最多 100 个可见结果。没有登录、使用私有令牌、解锁受限筛选或调用受保护接口。

榜单的收入帮助提示原文为「预计的内购收入已扣除平台和税费」。收入显示美元符号。全球所有商店的应用合并值不能解释为美国 iOS 值。测试美国或单独 iOS 筛选时未取得公开数值；1,000 结果选项显示锁定，没有采集。

保存 12 组可见榜单、1,200 行，去重得到 509 个带 Apple ID 的应用。Google Play 链接不按应用名猜测 Apple ID。当前美区工具 Top 200 匹配 83 个应用：月下载范围 25 个、月收入范围 82 个。

示例：Cleanup（1510944943）2026-09 全球全部商店月下载 >5M，月内购净收入 >$10M。数值是阈值范围，不是精确估算；所有 AppMagic 范围均排除在前部点估算均值外。没有公开范围的应用显示「未获取范围」，不填零。

- `data/appmagic-monthly-public-chart-rows.json`：公开界面原始行、筛选 URL、采集时间和收入口径提示。
- `data/appmagic-monthly-public-snapshot.json`：按 Apple ID 去重的月度范围及逐项来源。
- `scripts/normalize_appmagic.py`：从已保存的可见行重建快照，检查月份、地区、商店、单位与重复范围冲突。

```sh
python3 scripts/normalize_appmagic.py
python3 -m unittest discover -s tests -v
```

这是保存的公开范围快照；页面刷新仅获取新的 Apple 榜单并重新匹配，不会自动重抓 AppMagic。完整精确月数据和美国单商店数值仍未取得。

## 美国最近30天推算

同日验证应用详情页的小部件公开显示最近30天的全球范围和各国百分比。下载和收入各自有独立占比，不能混用，也不能用这些占比乘以 2026-09 自然月总量。

前部月下载、月收入及 AppMagic 末列改为美国推算：同一小部件的范围阈值 × 美国占比。Cleanup 下载 >5M ×17% 得近似阈值 ≈>850K；收入 >$10M ×52% 得 ≈>$5.2M。原页收入美国提示单独显示 >$5M，与近似阈值换算的粒度不同。

百分比是整数显示，存在舍入，因此 ≈> / ≈< 不能宣称为严格上下限，仍不是精确数据。最近30天起止日期未披露，应用合集未拆分商店；没有美国占比的指标不推算、不填零。全球来源的混合均值不再显示在前部美国列。

原始页面数据：`data/appmagic-us-share-raw.json`；美国推算：`data/appmagic-us-public-snapshot.json`。采集同时验证详情页 URL 中的 Apple ID 与页面商店链接 ID 一致，避免页面尚未加载时串入其他应用数据。

```sh
python3 scripts/normalize_appmagic_us.py
```

美国详情页最终采集 83 个应用，当前 Top 200 的美国近30天推算覆盖下载 47 个、收入 83 个。未显示美国下载占比的 36 个应用只展示收入；其余来源未覆盖的应用不填全球数值。

## 四家美国推算均值

按用户指定，将 IOSMRR、Sensor Tower、Appfigures 原始数值分别乘以 AppMagic 最近30天的对应美国占比，AppMagic 已推算的美国阈值直接使用，不能再次乘占比。IOSMRR 未披露原地区，假定为全球；Sensor Tower 是全球 iOS，Appfigures 为全球商店合并，借用的占比则来自 AppMagic 合并商店。各家月份、税费和收入定义未统一，因此属于跨来源的参考模型。

均值为可用美国推算数值之和除以来源数。所有范围符号后的阈值按数字参与，缺失不作零，单来源注明。原始值保留在快照，页面悬停可看换算过程。Cleanup 美国下载四个数值为 340K、340K、1.02M、850K，均值 637.5K；收入为 $5.72M、$5.72M、$7.8M、$5.2M，均值 $6.11M。公式在 `scripts/us_utilities.py` 的 `estimate_us_monthly`，边界校验见 `tests/test_us_provider_average.py`。

本次验证：37 项测试通过；200 个唯一 Apple ID；200 行美国均值逐项对账一致。来源美国推算覆盖（任一指标）IOSMRR 82、Sensor Tower 6、Appfigures 72、AppMagic 83 个应用，下载均值覆盖 47、收入均值覆盖 83。缺失和地区占比不明的行均保持不可用，没有按零补齐。
