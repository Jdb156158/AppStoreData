# 美国优先、全球备用

用户2026-10-15最新指令：如果美国区没有，就用全球。这替换了先前的其他地区占比代算方案。

下载和收入分别选择：有同一指标的美国推算值就使用；否则直接使用各来源原始全球总量。
IOSMRR 原始地区未披露，沿用既有“按全球参考处理”的假设，并在网页注明。
不再要求必须有 AppMagic 地区分布：IOSMRR、Sensor Tower、Appfigures 有原始总量即可参与全球参考均值。
美国推算仍使用 AppMagic 的同指标美国占比；范围阈值按既有规则参与均值并保留范围符号。

- 单元格及均值的 `shareBasis` 为 `us` 或 `global`。
- 全球口径的 `usPercent`、`sharePercent` 保持 null，不制造美国占比。
- 数值为零的已取得数据参与均值；缺失不当作零，所有来源缺失时显示未取得。
- `usMonthlyAverage`、`usEstimates` 保留兼容字段名，具体口径以 `shareBasis` 为准。
- 网页、来源说明及日报图片均标明美国或全球；原始统计时期和商店口径说明保留。

验证包括美国优先、没有任何地区分布仍可使用全球、忽略历史其他地区代理、AppMagic 不重复缩放、
下载收入不借用比例、真实零与缺失、范围符号和无数据的处理。本次不额外发送飞书测试消息。
