# 美国区最近30天评论分析

最后一列可打开评论详情：近30天文字评论差评率、差评主题与最新原文。

- 根据用户2026-10-14确认的新口径：差评率 = 近30天美国区取得的1–3星文字评论数 ÷ 同期取得的全部1–5星文字评论数，不包含只评星而没有文字的用户。
- 使用完整采集样本的计数，不以展示列表长度代替分母。达到RSS条数上限或分页失败时，计算已取得样本的差评率并明确标记“部分样本”；无样本显示“—”，有样本但没有1–3星评论时显示0%。
- Apple Customer Reviews RSS 不提供全量评星数据，`ratings: null` 保留为源数据事实；新的差评率不读取该字段。累计评分数、平均分以及点点当前星级累计分布仍可取得，但不参与30天文字差评率。
- 评论采样使用美国 RSS、`sortby=mostrecent`，每页50条、最多10页，按 `updated` 筛选采集时刻往前30天，去重评论ID，保留最新版本。接口有容量限制；翻页失败或达到500条仍未跨过窗口时标记为不完整样本。
- 主题是固定关键词规则匹配；每条评论在同一主题最多计1次，可归入多个主题。展示最多10个主题及已采集样本中全部1–3星原文，不再截断到30条；中文机器翻译见 review-translations.md。详情数量不足已统计差评数时明确提示尚未补齐。
- `scripts/review_analysis.py` 采集200个上榜应用，写入 `data/review-analysis.json`。`--publish` 使用已有 Keychain 同步令牌上传至 Sites `/api/review-analysis`，R2保存最新快照；静态快照仅作初始后备。
- 现有每日飞书推送成功后更新评论，评论采集失败不重发群消息。网页显示实际采样窗口及采集时间；“刷新数据”读取当前已保存评论，不会在浏览器现场重爬。

验证：窗口边界、1–3星分类、评论去重、改星后最新版本、主题计数；前端以采集的全部文字评论为分母，拒绝不可用数据、错误地区、非法计数和零分母，区分0%与缺失。

2026-10-14 首轮采集154个接口成功返回，46个接口暂时返回403。降并发并对暂时性错误做一次延迟重试后，200个接口均成功返回；5个应用受500条分页上限影响。当前在线R2快照包含8,823条窗口内文字评论，其中3,289条为1–3星。在线R2接口、本地数据文件和部署静态后备已同步为重试后的采集结果。

点点当前账户的 Cleaner Guru 美国区“近30天 / 新增评价趋势”导出已验证：2026-09-15 至2026-10-14，星级列含正负数，例如2026-10-12五星−10、四星−1、三星−3。这是快照净增减，不能按新增全量评星事件作分母。
